# Dearly Collection — Luxury Digital Wedding Invitations

The **Dearly Collection** by [InviteStory](https://invitestory.in) is an exclusive collection of luxury interactive digital wedding invitations designed for couples who want an unforgettable digital unboxing experience.

---

## Key Features

- **Wax-Seal Envelope Unboxing**: Interactive animated wax-seal opening ritual.
- **Email RSVP Built-In**: Guests submit attendance, guest counts, and dietary notes directly to the host's email inbox.
- **Optional Photo Gallery**: Space for curated couple portraits and moments.
- **Ambient Hero Loop**: Video backdrop loops for an immersive entrance.
- **Event Schedule & Calendar Sync**: Timeline with 1-tap Google Calendar save.
- **Venue Directions**: 1-tap Google Maps navigation.
- **Background Music**: Integrated audio player with custom soundtrack.
- **24-Hour Express Turnaround**: Concierge delivery within 24 hours.

Each template is 100% self-contained. Future edits only require updating `wedding-data.js` inside each template folder.
